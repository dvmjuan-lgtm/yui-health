개인정보처리방침 (Privacy Policy)

시행일: 2026-11-25

접근하는 데이터

소유자 본인의 Google 계정 동의를 받아 Google Health API의 읽기 전용 범위(활동·운동, 수면, 건강 지표·측정값)만 조회합니다. 데이터를 쓰거나 지우지 않습니다.

사용

조회한 데이터는 소유자 본인의 건강 기록 정리와 요약에만 씁니다. 광고, 판매, 제3자 제공에 쓰지 않습니다.

저장

인증 토큰은 소유자 개인 컴퓨터에 저장합니다. 조회한 데이터는 소유자 개인 컴퓨터에 저장하며, 소유자 본인만 접근하는 비공개 백업 저장소(GitHub 비공개 저장소)에 백업합니다.

처리·전송

소유자에게 건강 요약을 만들어 주기 위해 조회한 데이터를 AI 모델 서비스(Anthropic Claude)로 처리하고, 만든 요약은 소유자 본인의 카카오톡으로 보냅니다. 그 밖의 제3자에게 제공하지 않습니다.

Google 사용자 데이터

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

삭제·철회

소유자는 언제든 Google 계정의 '서드 파티 연결'에서 접근 권한을 철회할 수 있고, 저장된 데이터는 소유자 컴퓨터와 백업 저장소에서 지울 수 있습니다.
